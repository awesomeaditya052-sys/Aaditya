AADITYA CHOUKSE — PERSONAL PORTFOLIO
====================================

Files:
- index.html          Main website content
- style.css           Layout, colors, responsive design and animations
- script.js           Mobile menu, scroll progress and reveal animations
- assets/aaditya-portrait.png  Your portrait

PREVIEW LOCALLY
1. Extract the ZIP.
2. Open index.html in Chrome, Edge, or Firefox.
   (For best results, use VS Code + the Live Server extension.)

IMPORTANT BEFORE PUBLISHING
1. Confirm the education details and add your college names / dates in index.html.
2. Replace your.email@example.com with your real professional email.
3. Update LinkedIn, GitHub, and Instagram links with your own profile URLs.
4. Add real completed projects and remove any skill you cannot confidently discuss.
5. The page currently uses a portrait with a transparent-looking background; if its black background appears, use a transparent PNG for the cleanest white-page effect.

PUBLISH FOR FREE WITH GITHUB PAGES
1. Create/sign in to a GitHub account.
2. Create a new public repository named aaditya-portfolio.
3. Upload the contents of this folder (not the ZIP itself).
4. Open repository Settings → Pages.
5. Under Build and deployment, choose Deploy from a branch; select main and /(root), then Save.
6. After deployment, GitHub will show your public website address.
